# DetailFlow

Простое Android-приложение для мастера детейлинга: расписание, клиенты, заказы,
настраиваемые услуги, фотографии до/после и краткая финансовая сводка.

## Сборка

Требуются JDK и Android SDK 36. В текущем окружении достаточно выполнить:

```bash
./build.sh
```

Готовый установочный файл появится как `DetailFlow-debug.apk`. Версия приложения
задаётся в `version.properties`.

Все рабочие данные сохраняются только на устройстве через системное локальное
хранилище Android. Интернет используется только для проверки обновлений, если в
приложении настроен публичный GitHub-репозиторий.

## Обновления через GitHub

1. Создайте GitHub Release с тегом версии, например `v0.3.0`.
2. Приложите к релизу APK-файл, собранный с тем же keystore.
3. В приложении откройте «Ещё → Обновления» и укажите `владелец/репозиторий`.

Приложение проверяет последний релиз каждые 6 часов, выбирает первый `.apk`,
проверяет версию, пакет, подпись и доступный SHA-256 digest, а затем предлагает
системную установку. На Android нужно один раз разрешить DetailFlow установку из
этого источника. Закрытые репозитории без токена не поддерживаются.

### Автоматический выпуск

Workflow `.github/workflows/release.yml` запускается по тегу `vX.Y.Z`, собирает
APK, проверяет подпись и создаёт GitHub Release. Перед первым запуском workflow в
репозитории необходимо создать Actions Secret `DETAILFLOW_KEYSTORE_BASE64` с
локальным файлом подписи, закодированным в Base64.

Значения секретов нельзя публиковать в файлах репозитория или переписке. Тег
должен совпадать с `VERSION_NAME`, например `v0.11.0`.

## Установка на телефон

1. Передайте `DetailFlow-debug.apk` на Android-телефон.
2. Откройте файл и разрешите установку из этого источника, если Android попросит.
3. Нажмите «Установить».

При подключённом телефоне с включённой USB-отладкой можно установить командой:

```bash
/home/vadim/OrbisCalculator/android-sdk/platform-tools/adb install -r DetailFlow-debug.apk
```

Это локальная тестовая подпись. Для публикации в RuStore или Google Play нужно
будет создать отдельную постоянную release-подпись и увеличить версию приложения.
