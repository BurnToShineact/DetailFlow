# История изменений

## 0.2.0

- Добавлена проверка обновлений через публичные GitHub Releases.
- Добавлена безопасная загрузка APK через системный DownloadManager.
- Перед установкой проверяются версия, имя пакета, подпись и SHA-256 digest.
- Добавлена ежедневная автоматическая и ручная проверка обновлений.

## 0.1.0

- Первая рабочая версия: расписание, клиенты, заказы и настраиваемые услуги.
- Фотографии до/после и краткая финансовая сводка.
