# Безопасность обновлений

DetailFlow принимает обновление только при выполнении всех условий:

- APK относится к пакету `com.detailflow.app`;
- номер версии APK выше установленного;
- APK подписан тем же сертификатом;
- SHA-256 совпадает, если GitHub Release предоставляет digest.

Файл подписи (`*.keystore` или `*.jks`) нельзя публиковать в репозитории. Для
GitHub Actions он передаётся только через зашифрованные GitHub Actions Secrets.
